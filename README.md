# Obsidian Beige Workstation

这是从本地 Obsidian Vault 导出的工作站界面配置。

## 已包含

- `dandan-workstation-home` 首页插件源码和样式
- 暖米色 CSS snippets
- 启用工作站插件和 CSS 的必要 `.obsidian` 配置

## 未包含

- Vault 内的 Markdown、图片、附件和其他文件
- 工作站运行数据（待办、灵感、工作进度）
- `workspace.json`、备份文件和其他插件目录

将这些文件复制到另一个 Vault 的 `.obsidian` 目录后，再在 Obsidian 中启用对应插件和 CSS snippets。
